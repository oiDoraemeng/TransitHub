# 指纹题参考样本回复

智能分组增加独立的 `fingerprintReplyEnabled` 开关，创建时默认关闭。
开启后，完整命中题面的请求直接返回所请求模型的公开参考样本，不创建上游 Key、不调用模型、不占用上游并发，也不作为上游健康信号。回复沿用请求模型名，usage 为零，并带 `X-TransitHub-Response-Source: reference-replay`、参考模型和样本摘要响应头。参考样本不能证明实际在线模型身份。

## 匹配边界

- [lm-detector](https://github.com/Ikaleio/lm-detector/tree/e0472890bea827d15ca883636a77d4c10bbe843b)：五种语言、102,500 个完整组合。
- [ModelTrace](https://github.com/xqy2006/ModelTrace/tree/09a0ae5009d943aa6cb5dd3c914b83b7e70826ac)：42,000 个在线题面组合、36 个已知完整 enrollment 探针，以及十种语言的插件 fork JSON 数组题面。
- 每个模板的多组必要特征必须全部满足，再校验整段结构和数量范围。单独出现 `355`、关键词散落在历史中、解释或翻译题面、引用代码块、附加任务均不能触发。
- 支持 Chat Completions、Responses 和 Anthropic Messages 的 JSON 与 SSE。只接受单条完整用户任务，可以附带 system/developer 消息；多轮历史、媒体、缓存上下文引用和工具请求继续原有流程。插件工具提交题不伪造工具结果。
- 未匹配请求继续现有分流。已匹配但模型库或数据库不可用时返回明确的本地 503，不降级到其他模型或上游。

## 样本与去重

内置 26 个模型标签共 2,290 条公开样本：13 个 Claude 型号的 652 条，以及 13 个 GPT 型号的 1,638 条。模型标签沿用原始采样请求，未独立验证这些标签对应的真实模型。破折号版本别名与点号版本共用历史，Haiku 4.5 日期别名也共用历史；支持 GPT 的 `openai/` 前缀和 Claude 的 `anthropic/` 前缀，不会猜测未知版本或用其他型号替代。

GPT 来源固定为 lm-detector `643587185bf9c54b0c94ec6b2bed600f764177ec` 和 ModelTrace `09a0ae5009d943aa6cb5dd3c914b83b7e70826ac` 的公开参考记录；详细来源及 SHA-256 见 `fingerprints/gpt-source-manifest.json`。导入时剔除 11 条截断记录，没有补数、截取或重新排列整数。lm-detector 合并展示的 `gpt-6-astra/6.1-sol` 按原始请求中的模型字段分别归入 `gpt-6-astra` 与 `gpt-6.1-sol`，不互相设为别名。

样本保留原整数序列和原文本；JSON 数组题只调整序列的序列化格式，不补数、截断或重排。部分公开样本少于题面要求数量，沿用源库原样返回；因此不承诺所有第三方检测版本都判定有效。

每个工作区、每个规范模型排除最近 **30 道已选样本**，按常规每轮三题覆盖十轮。数据库事务和行锁处理多 Key、跨分组、并发和重启。取消发生在选择后时仍消耗该次选择。客户端额外重试、超过三题的轮次和多个客户端交错执行会消耗此窗口；协议不提供可靠的轮次 ID，因此不宣称这些情况下也能识别十个独立轮次。并发响应的到达顺序可能不同于事务选择顺序。

## 延迟与验证

每次先随机等待 **3–9 秒**，客户端取消可立即终止。依据 2026-11-27 查询的 Kiro 普通分组最近 24 小时日志：输出 300–1500 token 的同步请求 9,964 条，中位 3.315 秒、P75 5.965 秒；流式请求 16,760 条，总耗时中位 6.189 秒、P75 9.061 秒。这是参考回复的等待区间，并不仿真上游逐 token 输出过程。

Go 回归覆盖全部 144,500 个在线组合、36 个固定探针、820 个插件题面（工具题保持不回复）、440,792 个构造反例、参考序列 SHA-256、三种协议与流式、关闭开关、取消、故障和 PostgreSQL 原子选样。构造反例通过不代表任何可能的用户意图都能从相同文字中识别。

数据及导入工具位于 `backend/internal/modules/model_proxy/fingerprints` 和 `scripts/prepare-fingerprint-*.{py,mjs}`，两项目 MIT 授权随库保留。扩充时只能引入可追溯的真实公开样本，保持序列摘要唯一。
